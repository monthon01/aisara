ตัวอย่างเทคโนโลยี AIS (จำลอง)

หน้านี้เป็นต้นแบบสาธิตแนวคิดเท่านั้น ยังไม่ได้เชื่อมต่อบริการหรือเครือข่าย AIS จริง

AIS 5G MEC, AIS Cloud X และ Paragon Platform ที่แสดงด้านล่างเป็นภาพจำลอง ไม่มีการเรียกใช้ระบบ AIS จริง ส่วนเสียงพูดและการรู้จำเสียงใช้ความสามารถของเบราว์เซอร์

1. AIS 5G MEC — จำลอง

จำลองแนวคิดการประมวลผล Edge และ Low Latency เท่านั้น เว็บไซต์นี้ไม่ได้เชื่อมต่อ AIS 5G MEC หรือเครือข่ายจริง

2. AIS Cloud X — จำลอง

จำลองแนวคิดคลาวด์และ NLP เท่านั้น การอ่านออกเสียงใช้ Speech Synthesis ในเบราว์เซอร์ ไม่มีการเรียก AIS Cloud X

3. Paragon Platform — จำลอง

ภาพประกอบแนวคิดแพลตฟอร์มบริหารจัดการเท่านั้น ยังไม่มีการเชื่อมต่อ Paragon Platform หรือระบบจริง
